📘 方法说明 · 为什么用 FDR 控制的交互发现

传统方法常只报告"主效应"（每个特征各自的重要性），难以判断哪些特征是"协同起作用"的。Diamond 基于 model-X knockoffs 框架：

  1. 为每个特征生成一个" knockoff 副本"（与该特征统计等价、但与目标无关）；
  2. 用模型（LightGBM / XGBoost）+ SHAP 计算每对特征的交互强度；
  3. 用原始特征与 knockoff 的对比构造统计量，在给定 目标 FDR 下筛选"真交互"，自动控制误报比例。

💡 建议：特征数适中（如 10–80 列）效果最佳；样本量越大，FDR 控制越稳。本网页版采用轻量 CPU 路径（knockoffsdiag + 树模型 + SHAP）。

本文提出 Diamond：将 model-X knockoffs 框架用于特征交互发现，在控制错误发现率（FDR）的前提下稳健地找出真正协同作用的特征交互。本网页即基于该方法（轻量 CPU 路径）实现。
